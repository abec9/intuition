# Интуиция

Психологическая браузерная игра про скрытые профессии. В партии шесть персонажей, одна искомая профессия и пять раундов вопросов: **6 → 5 → 4 → 3 → 2**. Игрок может исключать персонажей в любой момент. Профессия исключённого персонажа раскрывается сразу, остальные — в финале.

Проект лежит здесь:

```text
/Volumes/WD2TB/Projects/games/intuition
```

Полная документация: [docs/README.md](docs/README.md).

## Быстрый запуск

Нужен Node.js 22 или новее и запущенная LM Studio с загруженной разговорной моделью.

```sh
cd /Volumes/WD2TB/Projects/games/intuition
npm start
```

Открыть:

```text
http://127.0.0.1:4173/
```

На macOS можно дважды щёлкнуть:

```text
Запустить игру.command
```

## Что уже собрано

- 36 постоянных карточек людей с портретами, именами, возрастом, характером и подробным личным описанием.
- 50 современных профессий в `professions.json`.
- Случайная искомая профессия в каждой партии: цель выбирается из шести профессий текущего набора.
- Ротация портретов и очистка межигровой памяти после каждых трёх успешно созданных партий.
- Личная история диалога для каждого персонажа.
- AI-based проверка вопросов и ответов через локальную модель.
- Настроенный баланс: ранние ответы дают мягкие признаки, поздние — более конкретные профессиональные критерии без прямого раскрытия.

## Как работает новая партия

Сервер выбирает шесть портретов, читает `professions.json`, назначает шесть профессий и выбирает цель. Модель на этом этапе не вызывается.

Модель нужна во время разговора. Один ответ обычно проходит через три локальных этапа:

1. `question_intent` — понять, это обычный вопрос или попытка раскрыть профессию.
2. `human_draft` — написать живую реплику персонажа.
3. `reply_review` — проверить, не выдала ли реплика профессию, не соврала ли о роли и дала ли полезный материал для сравнения.

Баланс строится не на заготовленных репликах под одну профессию. Любая профессия из каталога даёт модели описание работы, типичные критерии качества, мягкие подсказки и ограничения. Поэтому игра должна оставаться угадываемой и при другой случайной цели, если сама профессия хорошо описана в `professions.json`.

OpenAI API в рантайме игры не используется.

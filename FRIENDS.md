# Как дать друзьям поиграть

Основная инструкция теперь находится в [docs/RUNBOOK.md](docs/RUNBOOK.md). Этот файл оставлен как короткая памятка.

## Где лежит игра

```text
/Volumes/WD2TB/Projects/games/intuition
```

В этой папке находятся сервер, интерфейс, портреты, каталог профессий и файлы запуска.

Новая партия собирается из `professions.json`. LM Studio нужна для ответов персонажей во время диалога.

## Друзья в одной Wi-Fi или домашней сети

1. Убедись, что LM Studio запущена и модель загружена.
2. Дважды щёлкни `Запустить для друзей.command`.
3. Оставь открывшееся окно открытым.
4. Отправь друзьям адрес, который появится в этом окне.

Сетевой запуск использует:

```text
HOST=0.0.0.0
PORT=4174
```

Обычная локальная игра остаётся доступна на:

```text
http://127.0.0.1:4173/
```

Если ссылка не открывается, проверь, что устройства в одной сети, Wi-Fi не гостевой, macOS разрешила входящие подключения к Node.js, а компьютер не ушёл в сон.

## Друзья через интернет

Нужна публичная ссылка на локальный сервер. Для разовой проверки можно поднять туннель и запустить игру с `PUBLIC_ORIGIN`, равным выданному HTTPS-адресу:

```sh
PORT=4175 PUBLIC_ORIGIN='https://точный-адрес-туннеля' npm start
```

`PUBLIC_ORIGIN` обязателен: сервер принимает игровые действия только со страницы с разрешённым origin.

Временная публичная ссылка доступна любому, кто её получил. Для постоянной игры лучше отдельно настраивать доступ.

## Одновременная игра

- Node.js и LM Studio нужны только на твоём компьютере.
- У каждого браузера своя cookie-сессия.
- Две обычные вкладки одного браузера делят одну партию.
- Приватное окно или другой браузер обычно создают отдельную партию.
- После перезапуска сервера активные партии пропадают.

# Диалоги и секреты

В игре «Интуиция» реализована система обработки диалогов, работающая на локальной модели LM Studio. Основным улучшением архитектуры является оптимизация процесса генерации: теперь один ответ требует 2 запросов вместо 6. Это достигается за счет того, что актер сразу генерирует живую реплику с учетом полного контекста: личного диалога, биографии, знаний и скрытой профессии.

После генерации текст проходит через отдельный редактор, который выдает JSON-вердикт. Утвержденный текст отображается пользователю без дальнейших переработок. На уровне кода установлены жесткие блокировки на:
* явное признание в профессии;
* прямой вердикт на догадку пользователя;
* использование служебных токенов;
* ложную смену ответов «да/нет» при исправлении текста;
* подмену основной работы текущим моментом.

Система распознает все 50 профессий в вопросах пользователя, даже если они не входят в выбранную шестерку. Карта профессий других игроков не передается модели. Допускаются общие знания и факт работы за компьютером. При нарушении условий срабатывает механизм одной повторной генерации с проверкой (максимум 4 вызова). Неуспех или отмена действия не расходуют вопрос. История диалогов изолирована для каждого персонажа.

Генерация и проверка выполняются локально, API OpenAI не используется. Текущая скорость работы не замерена. Данная архитектура снижает риск некорректных ответов, но не является гарантией отсутствия галлюцинаций.

**Ограничение:**
Сложные косвенные утечки и фактические ошибки могут проходить проверку модели.

# Запуск и доступ для друзей

## Где лежит проект

Основная папка игры:

```text
/Volumes/WD2TB/Projects/games/intuition
```

Зеркало ChatGPT-проекта может существовать отдельно, но рабочая версия игры находится на внешнем диске в папке выше.

## Что нужно установить

- Node.js 22 или новее.
- LM Studio с загруженной разговорной моделью.

В проекте нет npm-зависимостей. `npm install` для текущей версии не нужен.

## Локальный запуск

Вариант для терминала:

```sh
cd /Volumes/WD2TB/Projects/games/intuition
npm start
```

Вариант для macOS:

```text
Запустить игру.command
```

Адрес игры:

```text
http://127.0.0.1:4173/
```

## LM Studio

По умолчанию игра ищет LM Studio здесь:

```text
http://192.168.1.192:1234
```

Сервер модели должен быть включён, а модель должна быть загружена. Игра сама ничего не скачивает и не меняет модель.

Проверка статуса в игре идёт через:

```text
GET /api/status
```

Если LM Studio недоступна, партия может создаться, но вопрос персонажу не будет отправлен.

## Переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `4173` | Порт игрового сервера. |
| `HOST` | `127.0.0.1` | Адрес, на котором слушает сервер. |
| `PUBLIC_ORIGIN` | пусто | Внешний origin, который сервер разрешает для POST-запросов. |
| `LLM_BASE_URL` | `http://192.168.1.192:1234` | Адрес LM Studio. |
| `LLM_MODEL` | первая загруженная модель | Предпочтительная модель, если она загружена. |
| `PROFESSIONS_FILE` | `./professions.json` | Альтернативный путь к каталогу профессий. |

Пример:

```sh
LLM_BASE_URL='http://127.0.0.1:1234' PORT=4173 npm start
```

## Игра для друзей в одной сети

Запусти файл:

```text
Запустить для друзей.command
```

Он стартует сервер на сетевом адресе и покажет ссылку для устройств в той же сети. Обычно это отдельный порт, чтобы локальная игра на `127.0.0.1:4173` не мешала сетевой.

Друзьям нужен только браузер. Node.js и LM Studio нужны только на твоём компьютере.

Если ссылка не открывается:

- проверь, что устройства в одной Wi-Fi или LAN;
- убедись, что это не гостевая сеть с изоляцией клиентов;
- разреши входящие подключения для Node.js в macOS;
- не давай компьютеру засыпать;
- проверь, что LM Studio доступна самому серверу игры.

## Игра через интернет

Для быстрой проверки можно использовать временный туннель. Схема такая:

1. Поднять туннель на локальный игровой порт.
2. Получить публичный HTTPS-адрес.
3. Запустить игру с `PUBLIC_ORIGIN`, равным этому адресу.
4. Отправить ссылку друзьям.

Пример с отдельным портом:

```sh
cloudflared tunnel --url http://127.0.0.1:4175
```

Во втором окне:

```sh
cd /Volumes/WD2TB/Projects/games/intuition
PORT=4175 PUBLIC_ORIGIN='https://адрес-туннеля.example' npm start
```

`PUBLIC_ORIGIN` нужен не для красоты. Сервер принимает игровые POST-запросы только с разрешённых origin, чтобы случайная чужая страница не могла отправлять действия в открытую игру.

Временная ссылка публичная. Любой, кто её получил, сможет открыть игру.

## Сессии игроков

Сессия хранится в памяти сервера и привязана к cookie `intuition_session`.

Практические последствия:

- обновление страницы сохраняет текущую партию;
- обычные вкладки одного браузера делят одну партию;
- приватное окно обычно создаёт новую партию;
- другой браузер создаёт новую партию;
- перезапуск Node.js сбрасывает все активные партии.

Сервер хранит до 100 сессий. Старые неактивные сессии очищаются при создании новых.

## Очистка межигровой памяти

После каждых трёх успешно созданных партий сервер очищает межигровую память для следующей генерации:

- сбрасывает список использованных портретов;
- перестаёт учитывать прошлую партию при выборе следующей;
- старая партия заменяется только после успешного создания новой.

Это правило относится к памяти игрового сервера, а не к внутренним логам LM Studio.
